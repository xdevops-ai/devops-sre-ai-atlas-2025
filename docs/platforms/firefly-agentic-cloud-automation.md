# Firefly (Agentic Cloud Automation)

**Evidence reviewed: 14 November 2026.** Official documentation/announcements; no independent runtime test.

## Identity and availability

Firefly Cloud Resilience + Thinkerbell AI; vendor product page

## Is it relevant to your team?

**Why shortlist it:** Evaluate cloud inventory, drift understanding, IaC generation and recovery-oriented workflows.

**Pilot question:** Can a pilot show the source-of-truth mapping, proposed change and recovery evidence for one controlled drift scenario?

This is editorial evaluation guidance inferred from the documented scope, not a product guarantee. Confirm contract, region, deployment model and feature entitlement with the provider.
