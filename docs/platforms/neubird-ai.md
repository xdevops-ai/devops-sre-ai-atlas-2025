# NeuBird AI

**Evidence reviewed: 14 November 2026.** Official documentation/announcements; no independent runtime test.

## Identity and availability

documented commercial investigation platform and installable MCP interface; public docs undated.

## Is it relevant to your team?

**Why shortlist it:** Bring connected operational investigations into web, IDE, terminal or MCP-client workflows.

**Pilot question:** Can an engineer start an investigation, inspect status and retrieve evidence using the required client without granting unnecessary connector permissions?

This is editorial evaluation guidance inferred from the documented scope, not a product guarantee. Confirm contract, region, deployment model and feature entitlement with the provider.

## Scope and limitations

NeuBird investigates incidents from web, IDE, terminal and MCP clients over connected cloud and monitoring data. Its MCP interface runs locally and calls the NeuBird API; documented operations include investigations, connection management, project instructions and report review. Infrastructure-changing actions were not established by these sources. Hawkeye compatibility aliases do not represent a separate vendor.
