## Scope and limitations

NeuBird investigates incidents from web, IDE, terminal and MCP clients over connected cloud and monitoring data. Its MCP interface runs locally and calls the NeuBird API; documented operations include investigations, connection management, project instructions and report review. Infrastructure-changing actions were not established by these sources. Hawkeye compatibility aliases do not represent a separate vendor.
